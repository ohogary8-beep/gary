# 数据看板中心

这是一个标准 HTTP 数据看板合集网站。根目录页面负责看板目录、分类、搜索与独立更新计划；每个具体看板放在 `dashboards/<看板标识>/` 下。

- 看板地址：`dashboards/monthly-review/index.html`
- 更新计划：支持每月一次、每月两次、仅手动
- 通知选项：支持为单张看板配置钉钉通知

## 本地 HTTP 预览

在本目录运行：

```powershell
.\启动本地预览.ps1
```

然后访问 `http://127.0.0.1:4173/`。

本地预览依赖电脑开机，不能满足无人值守要求。当前页面中的计划设置是交互原型，保存后只写入当前浏览器，不代表云端任务已经启用。

## 目录约定

- `index.html`：合集首页
- `dashboard-registry.json`：看板目录与默认计划配置
- `dashboards/`：各具体数据看板
- `.work/`：构建、数据回执与质检中间文件

新增看板时只需增加对应子目录，并在 `dashboard-registry.json` 追加一条记录；不用复制整个合集网站。

## 云端自动执行目标

要实现电脑关机仍执行，需要把这个目录放到云端代码仓库或云端文件存储，并把 HTTP 网站部署到静态托管服务。随后由 Codex Web 定时任务按每张看板的计划调用云端 MCP、覆盖同名看板文件、发布站点，并通过服务端安全保存的钉钉机器人密钥发送成功或失败通知。

此方案不需要另购 OpenAI API Key，但会受 Codex/ChatGPT 订阅方案的任务额度与工作区策略约束。钉钉 Webhook 不应写入前端 HTML 或仓库明文。
